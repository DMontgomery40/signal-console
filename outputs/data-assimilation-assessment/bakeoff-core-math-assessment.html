Assessment Findings

What is legitimate

  • Board MAD now has a clean causal split: prebucket builds K-independent buckets, sweep applies K-dependent thresholds.
  • Warmup, trailing windows, and historical-prior fade are anchored to elapsed game time when PBP or scheduled timing exists, with fail-closed behavior when no anchor exists.
  • The current bake-off records skipped/not-scoreable rows instead of counting anchor gaps as misses.

What is still overconfident

  • The top recall rows, A09 and A06, catch 8/14 but require about 4.7 to 5.5 alert episodes per game and still show 67 to 69 outlier games.
  • Off-price rows A10/A11 have zero scoreable incidents because local microstructure coverage is absent for the relevant cases.
  • The game-state volatility surface still carries a fallback baseline and local constants that should not become durable calibration truth.

Bottom line

Treat the bake-off as a falsifiable scorecard, not a proof. The credible next step is not a fancier filter by itself; it is better observation coverage, alert-episode scoring, source/family de-duplication, and generated calibration provenance.

Not Evaluable

Off-price microstructure

A10 and A11 are not scored against any incident because the bake-off reports no local quote or microstructure coverage for those algorithm contracts across 15 otherwise anchored candidates. Do not call them misses or wins.

Kalman claims

A Kalman-style helper is present but unused in the current graph. The live output should not be described as Kalman-filtered unless that path becomes executable and tested against residual/innovation behavior.

Known-case completeness

Ten surfaced incidents lack exact UTC/PBP anchors and one lacks a usable normalized game id. Those are data-quality holes, not detector performance measurements.

Sources and Next Filters

Additional data sources

  • Persisted order-book snapshots near the mid price for Kalshi/Polymarket.
  • Trade direction, signed size, and depth near touch for order-flow imbalance.
  • Provider-native sequence numbers or ingestion lag metrics for source-lag windows.
  • Explicit quiet-time buckets so calm games are observations, not missing rows.
  • Incident registry fields that separate official correction, suspected correction, and archive-only lead.

Next filters worth testing

  • Episode-first scoring: merge fires within 90 seconds before optimizing recall.
  • Qn/Sn or quantile-range scale floor for short tied MAD windows.
  • Latency-tolerant source confirmation rather than same-bucket source confirmation.
  • Hierarchical historical priors with sample-strength shrinkage.
  • BOCPD or HMM regime rows after the observation contract includes zeros and source lag.
